#### C) THREE-SECTOR INCOME DETERMINATION MODEL (7 MARKS)
**Model Equations:** $$Y = C + I_0 + G_0$$ $$Y_d = Y - T$$ $$C = C_0 + b Y_d$$ $$T = T_0 + t Y$$

**Step 1: Express Equilibrium Level of Income ($Y^*$)**
Substitute $T$ into $Y_d$: $$Y_d = Y - (T_0 + t Y)$$
Group $Y$ terms on the left: $$Y - b Y + b t Y = C_0 - b T_0 + I_0 + G_0$$ $$Y [1 - b(1 - t)] = C_0 - b T_0 + I_0 + G_0$$
$$Y^* = \frac{C_0 - b T_0 + I_0 + G_0}{1 - b(1 - t)}$$

**(i) Impact of a unit change in Government Spending ($G_0$):**
$$\frac{\partial Y^*}{\partial G_0} = \frac{1}{1 - b(1 - t)}$$
- **Magnitude:** $\frac{1}{1 - b(1 - t)}$
- **Direction:** Positive (since $0 < b, t < 1$, the denominator is between 0 and 1, making the multiplier $> 1$).

**(iii) Impact of a unit change in Tax Rate ($t$):**
$$\frac{\partial Y^*}{\partial t} = \frac{\partial}{\partial t} \left[ (C_0 - b T_0 + I_0 + G_0) \cdot (1 - b + bt)^{-1} \right]$$
